# Mishra ji Desi vibe 🎶

A single-page desi music and Bhojpuri nostalgia website. Pick a mood, tap a song, enjoy.

## Edit songs
Open `index.html` and edit the `songs` array near the bottom. Each entry has a title (`t`), mood (`m`) and description (`d`).

## Deploy
Pure static site, no build step. Works on Vercel, Netlify or GitHub Pages (serve from the `main` branch root).

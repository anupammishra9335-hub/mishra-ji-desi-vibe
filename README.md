# Mishra ji Desi vibe 🎶

A single-page desi music and Bhojpuri nostalgia website. Pick a mood, press play, and the song plays right on the page through an embedded YouTube player.

## Edit songs
Open `index.html` and edit the `songs` array near the bottom. Each entry has a YouTube video ID (`id`, the part after `v=` in a watch link), title (`t`), artist or film (`a`), mood (`m`) and description (`d`). Pick videos whose owners allow embedding.

## Deploy
Pure static site, no build step. Served with GitHub Pages from the `main` branch root.
